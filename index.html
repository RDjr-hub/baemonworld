How to update this page

This is a plain HTML file — no account or app needed. Open it in any text editor (Notepad, TextEdit, VS Code) to make changes, then save and re-upload wherever it's hosted.

01 Find the video card you want to change inside the "VIDEOS" section (search the file for its current title).
02 Replace the href with the new YouTube link, and swap the video ID inside the thumbnail's image address to match.
03 Update the title/label text below the thumbnail, save the file, and re-upload it to your host.
